# Squared Snake - Gameplay Systems Prototype

Personal project of the famous Snake. 

Early gameplay programming prototype focused on grid-based movement systems and modular gameplay architecture.

Highlights:
Built a custom node/grid system for gameplay movement
Implemented segmented snake-body behavior through linked entity logic
Structured gameplay systems with separation between movement, grid, and food management
Explored reusable gameplay patterns and discrete movement logic
Developed as an independent gameplay programming exercise outside tutorial-driven workflows

Key Takeaways:
Gameplay system architecture
Entity relationship management
Grid-based gameplay logic
Code organization in Unity
Early experimentation with modular gameplay systems
Context

Originally developed around 5 years ago as part of my early gameplay programming exploration.

Sadly, due to professional workload and limited free time, I eventually lost access to my Google Play developer account. Additionally, the project became outdated for newer Android devices, so the game is no longer available on the Play Store.

## Tech Stack
* Unity Engine
* C#
* Git
