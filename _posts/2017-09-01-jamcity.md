# Game Developer (Sep 2017 - Jul 2019)

Contributed to the development and live operations of mobile titles with hundreds of thousands of active users across Android, iOS, Amazon, and Facebook platforms.<br>
Implemented gameplay systems, UI flows, live event features, and production-ready content pipelines using ActionScript 3, Adobe Flash, Starling Builder, and AIR SDK.<br>
Worked in fast-paced live production environments, collaborating with multidisciplinary teams to deliver updates, troubleshoot critical issues, optimize performance, and manage cross-platform mobile releases.

## Main Tasks
* Implement new features
* Bug fixing
* UI
* Performance optimization
* Loading Optimization
