Competitive multiplayer brick-breaker (Arkanoid-type) prototype built with Photon Quantum, focused on deterministic gameplay simulation, responsive controls, and scalable gameplay systems.

## Technical Highlights
* Implemented multiplayer gameplay using Photon Quantum deterministic simulation
* Developed gameplay systems around frame-based simulation architecture
* Built synchronized collision and gameplay interactions for multiplayer environments
* Structured gameplay logic separately from visual presentation systems
* Designed reusable gameplay components for bricks, balls, and player interactions
* Worked with rollback-safe gameplay constraints and deterministic state synchronization
* Iterated on responsive arcade gameplay within multiplayer simulation limitations

## Responsibilities
* Gameplay programming
* Multiplayer gameplay architecture
* Quantum systems implementation
* Simulation/gameplay logic
* Networking integration
* Gameplay iteration and balancing

## Technologies
* Unity
* Photon Quantum
* C#
* Deterministic networking
* ECS-oriented workflows
* Multiplayer systems
